# Atman Project

## Vision

Your memories you will never lose.

Software shifts.
Your data shouldn’t.
Keep what matters.

## Goals

- Local-first Software
  - Stay with data, shift the software
- Malleable Software
  - Simple tools, infinite composability
  - From docs to apps
- Version Control
  - History for everything, across all software

## Sub-projects

- Atman: Universal peer-to-peer sync engine
- Blacksmith: Doc-to-app framework
